# STORYVERSE — A World of Stories

**Every story has another world.**

STORYVERSE is a creative writing portfolio designed to showcase original storytelling and AI-assisted episodic story development. It brings stories to life through an interactive, vintage-inspired digital book experience.

## 🌐 Live Portfolio

**[Visit STORYVERSE]([YOUR-VERCEL-LIVE-LINK](https://storyverse-4gpvyipgu-shaz2.vercel.app))**

## 📖 About the Project

STORYVERSE is a collection of four interactive storybooks. Each book contains two sections:

- **Part I — Original Story:** The original story concept and narrative.
- **Part II — AI-Expanded Series:** Seven episodes expanding the original story into an episodic format.

Readers can explore individual books, read original stories, browse episodes, and navigate between episodes through an interactive reading experience.

## ✨ Features

- Four interactive digital storybooks.
- Animated book-opening experience.
- Original stories and seven-episode expansions.
- Individual episode reading pages.
- Next Episode navigation.
- All Episodes navigation.
- Vintage-inspired editorial design.
- Responsive layout for different screen sizes.

## 🛠️ Tech Stack

- **HTML5** — Website structure.
- **CSS3** — Styling, animations, and responsive design.
- **JavaScript** — Book interactions and navigation.
- **Vercel** — Deployment and hosting.
